Two things no sum can show

Do the hours become money?

Hours saved are only cash saved if the time goes into work that wins or keeps customers. For each automation on the next page we name where the time should go. If it doesn't go there, the saving only exists in a spreadsheet.

Is the result as good?

A faster follow-up that wins less often loses you money. Each automation has one measure to watch, such as the share of quotes accepted, and we check it against today's figure before and after.

Our rule

If we can't show you how a figure was worked out, and what would make it wrong, it doesn't go in the report.
